# Contributing to WhatsApp Business AI Bot

Terima kasih sudah mau berkontribusi! Setiap kontribusi sangat berarti.

## Cara Berkontribusi

### 🐛 Lapor Bug
1. Cek dulu apakah bug sudah dilaporkan di [Issues](../../issues)
2. Jika belum, buka issue baru dengan template **Bug Report**
3. Sertakan: steps to reproduce, expected behavior, actual behavior, screenshots jika ada

### 💡 Request Fitur
1. Buka issue baru dengan template **Feature Request**
2. Jelaskan use case dan manfaatnya
3. Jika bisa, sertakan mockup atau pseudocode

### 🔧 Submit Kode

```bash
# 1. Fork repo ini
# 2. Buat branch dari main
git checkout -b feature/nama-fitur-anda

# 3. Buat perubahan dan test
npm test

# 4. Commit dengan pesan yang jelas
git commit -m "feat: tambah integrasi Tokopedia"

# 5. Push dan buat Pull Request
git push origin feature/nama-fitur-anda
```

### Konvensi Commit Message
- `feat:` — fitur baru
- `fix:` — perbaikan bug
- `docs:` — perubahan dokumentasi
- `refactor:` — refactor tanpa perubahan fungsional
- `test:` — tambah atau perbaiki test

## Code Style
- Gunakan ESLint config yang sudah disertakan
- Jalankan `npm run lint` sebelum commit
- Tambahkan JSDoc untuk fungsi public
